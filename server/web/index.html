📖 PocketNAS Pro 连接与使用教程
✕
⚡ 文件闪传 (FastSend :2333 / fsend.cn) 使用教程

• 局域网网页直连：在电脑或其它手机浏览器输入 http://手机IP:2333 即可免登录直接浏览手机相册、视频，支持多文件高速批量下载与上传。

• 官方域名配对：访问 http://fsend.cn 扫码或输入配对码，跨网络轻松连接传输。

• 注意事项：请先在手机端打开「文件闪传」App 并保持后台运行，若端口被占用可在设置中自定义。

📺 WebDAV 局域网挂载教程 (Mac / Windows / 电视 · 推荐 ⭐)

• macOS 访达挂载：按 Cmd + K（或点击菜单栏「前往」➔「连接服务器」），输入 http://手机IP:5244/dav 点击连接即可挂载为本地原生网络磁盘卷标。

• Windows 映射网络驱动器：打开「此电脑」，点击顶部「...」或空白处右键「映射网络驱动器」，盘符选择 Z:，文件夹输入 http://手机IP:5244/dav 完成挂载。

• 智能电视 / 手机播放器 (Kodi / Infuse / 影视仓 / nPlayer)：添加 WebDAV 源，地址填入 http://手机IP:5244/dav，局域网极速直连 4K 原画免解压秒播。

⚡ 24/7 原生安全 FTP 服务使用教程

• 连接地址：ftp://手机IP:2121

• 认证模式：支持匿名免密登录（用户名留空或填 anonymous，密码留空）。

• 推荐客户端：手机端 MT 管理器、电脑端 FileZilla / WinSCP / Total Commander，千兆物理满速读写。

📁 SMB / CIFS 局域网网络邻居教程

• Windows 连接：在文件资源管理器地址栏输入 \\手机IP\PocketNAS 直接访问。

• macOS 连接：访达按 Cmd + K 输入 smb://手机IP/PocketNAS 连接。

• 提示：推荐通过「多系统工具箱」或手机内置 SMB 服务开启 445 端口共享。

📂 AList / OpenList 聚合网盘教程

• 浏览器访问：http://手机IP:5244

• 功能说明：在手机上配合 AListLite 运行，支持百度网盘、阿里云盘、115、OneDrive 与本地存储一体化聚合管理与 Web 预览。

🔒 SSH / SFTP 远程终端教程

• 连接命令：ssh root@手机IP -p 22

• 工具支持：Termius、PuTTY、JuiceSSH、FinalShell 等，获取完整 Android Root Shell 权限。

❓ 常见问题 FAQ

Q: 为什么电脑或电视打不开连接地址？

A: 请确保手机与电脑/电视连接在同一个 Wi-Fi 局域网（或路由器同一网段下），且路由器未开启 AP 隔离功能。

Q: 为什么手机 IP 发生变化？

A: 手机重新连接 Wi-Fi 时 DHCP 可能重新分配 IP，建议在路由器后台为手机绑定固定静态 IP。

Q: 熄屏后服务会不会被杀？

A: PocketNAS Pro 采用 Go 原生单进程守护，熄屏待机功耗仅约 0.3W；请在手机系统电池设置中将对应 Root 管理器（如 KernelSU/Magisk/AListLite）加入后台白名单/无限制。
