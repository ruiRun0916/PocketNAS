📖 PocketNAS Pro 多端挂载与使用教程
📺 WebDAV 局域网挂载教程 (推荐 ⭐)

• macOS 访达：桌面按 Cmd + K，输入 http://[手机IP]:5244/dav 连接即可将手机存储挂载为 Mac 原生网络磁盘。
• Windows 映射驱动器：打开「此电脑」，点击「映射网络驱动器」，文件夹输入 http://[手机IP]:5244/dav 即可分配盘符。
• 智能电视 / Kodi / Infuse / 影视仓：添加 WebDAV 视频源，端口 5244，路径 /dav，千兆局域网免解压秒播 4K 原画原盘！

🌐 Tailscale 远程穿透全端挂载教程

• 出差与户外直连：在电脑/电视登录 Tailscale，使用 http://[Tailscale固定IP]:5244/dav，无论何时何地均可直接挂载家里 NAS 手机进行 4K 播放与文件调取。
• 安全免公网：基于 WireGuard 端到端加密直连，免公网 IP，免端口转发。

⚡ 24/7 原生安全轻量 FTP 教程

• 连接端口：2121（支持匿名免密登录）。
• 手机端：推荐使用 MT 管理器 侧边栏 FTP 客户端，全盘文件极速读写。
• 电脑端：推荐使用 FileZilla / WinSCP，输入手机局域网 IP 与端口 2121，选择匿名连接。

📁 SMB / Windows 网络邻居教程

• Windows 访问：在文件资源管理器地址栏直接输入 \\[手机IP]\PocketNAS 或 \\[手机IP]。
• macOS 连接：访达按 Cmd + K 输入 smb://[手机IP]/PocketNAS，以“客人”身份连接。

❓ 常见问题与排错指引 (FAQ)

Q: 电脑或电视为什么连不上手机的 NAS？
A: 请确保手机与电脑/电视处于同一 Wi-Fi 局域网（或均连接到同一个 Tailscale 虚拟局域网），且路由器未开启 AP 隔离。

Q: 手机重新连接 Wi-Fi 后 IP 为什么改变？
A: 建议在路由器后台将手机的 MAC 地址绑定为静态 IP，或直接使用 Tailscale 分配的永久固定 IP。

Q: 熄屏待机后服务会被系统杀死吗？
A: PocketNAS Pro 采用 Go 原生极低功耗守护进程，待机仅约 0.3W；请在手机系统电池设置中将 Root 管理器（KernelSU/Magisk）加入白名单。
